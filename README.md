# SCD-25 Node.js + MongoDB Dockerized Application

This project is a Node.js application connected to a MongoDB database.  
The complete environment is containerized using **Docker** and orchestrated using **Docker Compose**.

---

## 📌 Features
- Node.js backend with REST API (`/stats`, `/export`)
- MongoDB database with persistent storage using Docker volumes
- Multi-container orchestration using Docker Compose
- Environment variables handled securely through `.env`
- Automatic image building using Dockerfiles
- Database persistence across container restarts
